# 📚 英语打卡学习应用

## 功能介绍

这是一个本地运行的英语学习打卡网页应用，包含两个独立计划：

### 1. 每日单词计划（30天）
- 每天约30个单词，共855个单词
- 分为**日常沟通词汇**和**简历专业词汇**两类
- 每个单词配有：音标、词性、中文释义、英文例句
- 覆盖：教育背景、实习经历、量化研究、机器学习、编程技能、面试表达等

### 2. 简历短语计划（20天）
- 每天20个短语，共400个短语
- 从你的真实英文简历中提取的固定搭配和专业表达
- 每个短语配有：中文释义、简历原文上下文
- 覆盖：教育背景、荣誉奖项、实习经历、因子研究、竞赛经历、技能栈、面试表达、反问环节等

### 3. 核心功能
- ✅ **每日打卡**：每个单词/短语可勾选"已掌握"
- 🎙️ **录音打卡**：每个单词/短语可录制朗读音频，支持回放和保存
- 📊 **学习统计**：总天数、已完成天数、已学单词数、连续打卡
- 📅 **打卡日历**：可视化查看每天的完成进度
- 🎧 **录音记录**：查看和回放所有保存的录音
- 💾 **数据导入导出**：支持备份和恢复学习进度
- 📱 **响应式设计**：适配电脑和手机屏幕

## 使用方法

### 电脑端
1. 打开文件夹 `C:\Users\32698\english-practice-app`
2. 双击 `index.html` 文件，用浏览器打开（推荐Chrome/Edge）
3. 开始学习打卡

### 手机端（推荐方式）
由于应用是纯本地网页，有两种方式在手机上使用：

**方式一：局域网访问（推荐）**
1. 在电脑上启动一个简单的HTTP服务器：
   ```
   cd C:\Users\32698\english-practice-app
   npx serve .
   ```
   或
   ```
   python -m http.server 8080
   ```
2. 确保手机和电脑在同一WiFi网络下
3. 手机浏览器访问 `http://电脑IP:端口号`（如 `http://192.168.1.100:8080`）
4. 在浏览器菜单中选择"添加到主屏幕"，即可像App一样使用

**方式二：传输文件**
1. 将整个 `english-practice-app` 文件夹传输到手机
2. 用手机浏览器打开 `index.html` 文件

## 数据存储说明

- 所有打卡记录和录音都保存在浏览器的 **localStorage** 中
- 清除浏览器数据会丢失学习进度，建议定期使用"导出学习数据"功能备份
- 录音最多保存50条，超过后最早的录音会被自动删除

## 学习建议

1. **每天固定时间学习**：建议每天学习30分钟，先单词后短语
2. **朗读+录音**：每个单词/短语都大声朗读并录音，回听自己的发音
3. **造句练习**：尝试用每个单词自己造一个句子
4. **复习巩固**：每周回顾一次已学内容，标记不熟悉的单词
5. **结合简历**：短语计划中的表达可以直接用于面试和简历修改
